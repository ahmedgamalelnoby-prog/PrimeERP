# PrimeERP

PrimeERP is a modern Enterprise Resource Planning (ERP) platform built with Python and FastAPI.

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- React
- Material UI

## Modules

- Authentication
- Dashboard
- Restaurant Management
- POS
- Inventory
- Purchasing
- Accounting
- CRM
- HR
- Payroll
- Reports
